# Воронка по ключевому слову под рилс

Работает только там, где подключён MCP ChatPlace: в заводе этого
инструмента нет и не будет — роли ходят `claude -p --tools ""`, а
`cli.clean_env` пропускает семь переменных. Привязка живёт здесь, в
сессии у человека.

## Что нужно от человека

Три вещи. Чего нет — спроси одной репликой, не начинай без них:

1. **Ключевое слово** — одно, своё, которого ещё нет в других воронках.
2. **Ссылка лид-магнита** — куда ведёт кнопка (пост канала, страница, файл).
3. **Какой рилс** — ссылка `instagram.com/reel/...`, кусок подписи или
   «последний».

Если ключ произносится в самом ролике, он уже есть в сценарии —
посмотри `cta` темы и спроси, он ли это.

## Порядок

### 1. Бот

`bots_list` → Instagram-бот бренда. У `lily_.space` это
`01a07112-3b04-7354-a1c7-3b7826fb7bc3`, но проверь списком: id бота
меняется при переподключении аккаунта.

### 2. Ключ не занят

`automations_list` → сверь `startMessages` всех воронок. Совпал —
скажи человеку, с какой именно, и возьми другой ключ. Два активных
триггера на одно слово дерутся молча.

### 3. Найти рилс

`automations_triggers_list_instagram_media` отдаёт триста постов одной
строкой на 340 КБ: **в контекст это не лезет** и приезжает файлом.
Разбирай файл скриптом, а не чтением:

```bash
./.venv/bin/python tools/chatplace_media.py <файл-ответа> --limit 10
./.venv/bin/python tools/chatplace_media.py <файл-ответа> --match "хук ролика"
```

Нужен столбец `id` — это media UUID. Числовой `mediaId` в триггеры не
годится. Ролик от поста отличается ссылкой: `/reel/` против `/p/`.

Покажи человеку найденный ролик ссылкой и подписью **до** создания:
привязка к чужому рилсу обнаруживается только по тишине в директе.

### 4. Создать воронку

Один вызов `automations_create_from_schema`, `status: "paused"`,
`botId` из шага 1. Шаблон ниже: семь шагов, подставляются ключ,
ссылка и тексты.

Потолки Instagram: 1000 знаков на сообщение, три кнопки, имя кнопки
двадцать знаков и без точек.

```json
{
  "name": "«КЛЮЧ» под рилс ГГГГ-ММ-ДД",
  "status": "paused",
  "steps": [
    {"stepId": 1, "type": "message", "coordinateX": 100, "coordinateY": 100,
     "content": "Привет! Вижу твой комментарий 🌿 Забирай материал — он по тому же, о чём ролик.",
     "callToAction": [{"name": "Забрать", "url": null, "type": "onetime", "nextStepId": 2}],
     "nextStepId": null},

    {"stepId": 2, "type": "action", "coordinateX": 560, "coordinateY": 100,
     "action": {"type": "add_tag", "tagNames": ["reel-КЛЮЧ-запрос"], "nextStepId": 3},
     "nextStepId": 3},

    {"stepId": 3, "type": "condition", "coordinateX": 1020, "coordinateY": 100,
     "condition": {"type": "check_subscription", "nextStepId": 4, "failedStepId": 7},
     "nextStepId": null},

    {"stepId": 4, "type": "message", "coordinateX": 1480, "coordinateY": 100,
     "content": "Держи 👇",
     "callToAction": [{"name": "Открыть материал", "url": "ССЫЛКА", "type": "multiple", "nextStepId": 5}],
     "nextStepId": null},

    {"stepId": 5, "type": "action", "coordinateX": 1940, "coordinateY": 100,
     "action": {"type": "add_tag", "tagNames": ["reel-КЛЮЧ-выдано"], "nextStepId": 6},
     "nextStepId": 6},

    {"stepId": 6, "type": "action", "coordinateX": 2400, "coordinateY": 100,
     "action": {"type": "make_conversion", "nextStepId": null},
     "nextStepId": null},

    {"stepId": 7, "type": "message", "coordinateX": 1480, "coordinateY": 350,
     "content": "Подписки пока не вижу 🙂 Подпишись на аккаунт и нажми кнопку — пришлю материал.",
     "callToAction": [{"name": "Готово", "url": null, "type": "multiple", "nextStepId": 3}],
     "nextStepId": null}
  ]
}
```

Тексты — заготовка, а не канон: перепиши под лид-магнит в голосе
бренда. Спокойно, без «срочно» и «только сегодня», без обещаний
результата. Голос — `core.md` папки бренда, раздел «Голос».

Два тега не для красоты: `запрос` считает, сколько людей дошло до
проверки, `выдано` — сколько получило ссылку. Разница между ними и
есть цена проверки подписки.

### 5. Привязать ключ к ролику

```
automations_triggers_set(
  automationId=<из ответа шага 4>,
  triggerTypes=["commentContains"],
  startMessages=["ключ"],
  mediaIds=["<media UUID>"],
  startFrequency=1, frequencyType="day")
```

- **`mediaIds` несовместимы с комбинированными группами триггеров.**
  Комментарий привязывается к ролику — значит `messageContains` в этот
  набор не кладётся. Нужен тот же ключ в директе — это **вторая**
  воронка, без привязки к медиа.
- **Пустой `mediaIds` это весь аккаунт**, а не ошибка. Промолчать здесь
  значит поставить ключ на все триста постов.
- `startFrequency` — кулдаун на человека. Сутки отсекают повторный
  комментарий под тем же роликом; `0` снимает ограничение.

### 6. Включить и показать

`automations_change_status` → active. Потом `automations_get_detail` и
сверь глазами: ключ, `medias`, адрес кнопки. Человеку верни коротко:
ключевое слово, ссылку на ролик, куда ведёт кнопка, имена тегов.

Активная воронка отвечает живым подписчикам — **включай только после
явного согласия человека**, как и публикацию.

## Проверить, что живое

`automations_get_detail` даёт статистику по каждому блоку:
`clientsCount` на шаге 1 — сколько пришло по ключу, `ctr` кнопки —
сколько открыло. Ноль на первом шаге через сутки после выхода ролика
значит, что ключ не ловится: смотри привязку к медиа и регистр слова.

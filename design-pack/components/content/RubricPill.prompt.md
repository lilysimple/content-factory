A rounded content-rubric / category tag in the brand pill style.

```jsx
<RubricPill tone="dark">ИИ для бизнеса</RubricPill>
<RubricPill tone="outline">Автоматизация</RubricPill>
<RubricPill tone="sage">Промпты</RubricPill>
<RubricPill tone="terracotta">Разбор профессий</RubricPill>
```

Use `dark` for the active rubric, `outline` for the rest; `sage`/`terracotta` tints mark special categories.

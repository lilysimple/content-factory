Dark infographic card foregrounding one big statistic, with an optional progress bar.

```jsx
<StatCard
  eyebrow="Метрика"
  value="−40%"
  label="времени на рутинные задачи после внедрения AI-ассистента"
  progress={60}
  from="было: 40 ч/нед"
  to="стало: 24 ч/нед"
/>
```

Reserve for a single hero figure per view. The number uses Manrope 800; the bar and range labels are optional.

# Контент-завод в Telegram — спека

Коробочный мультитенантный продукт: команда из семи агентов-ботов в супергруппе
Telegram, которая производит и публикует контент по профилю бренда клиента.

Версия спеки 1.1 · 13 августа 2026

---

## Документы

| Файл | О чём |
|---|---|
| `00-архитектура.md` | боты, топики, изоляция тенантов, площадки |
| `01-промпты-ролей.md` | общий каркас и семь промптов |
| `02-онбординг.md` | O0–O15, маски, распаковка бренда |
| `03-процессы.md` | четыре контура, недельный цикл, триггеры |
| `04-данные.md` | структура папки бренда, БД, статистика |
| `05-дашборд.md` | Mini App согласования |
| `06-запуск.md` | разовая настройка и ручная приёмка |
| `07-реализация.md` | **что выяснилось на сборке и живых прогонах** |

**Спека не дублирует код.** Промпты живут в `roles/*.md`, схема базы — в
`storage/db.py`, автоматическая приёмка — в `tests/`. Спека отвечает на
вопрос «почему так», а не «как именно»: копия, которая разъехалась с
оригиналом, врёт увереннее, чем её отсутствие.

## Что вошло в v1

| Роль | v1 | Комментарий |
|---|---|---|
| 🤝 Ассистент | ✅ полностью | онбординг, маршрутизация, состояние |
| 🔍 Ресёрчер | ✅ полностью | распаковка, недельная сводка, своя статистика. Метрики по слотам — v2 |
| 🎯 Стратег | ✅ полностью | план недели, дашборд, узкое место |
| ✍️ Редактор | ✅ полностью | тексты для Telegram |
| 🎬 Редактор Reels | ✅ полностью | суфлёрный текст, живьём не прогонялся |
| 🎨 Дизайнер | ✅ полностью | HTML и PNG по ТЗ площадки |
| 📤 Публикатор | ✅ Telegram | Instagram и YouTube — v2 |

**Замкнутая цепь v1:** онбординг → план → дашборд → тексты → публикация в Telegram.

Площадки v1: **планирование** на Telegram, Instagram и YouTube,
**публикация** только в Telegram. Слоты вне Telegram человек выкладывает
руками: Instagram требует Business-аккаунт с ревью приложения, YouTube —
OAuth владельца. VK и LinkedIn из проекта исключены.

Запуск: локально, polling, тестовый канал.

## Источники

Спека собрана из двух рабочих систем, а не с нуля:

- **Скиллы Лили** (`Lily/Skills/`) — механика ролей, признаки машинного текста,
  правило трёх, чек-листы, конвейер.
- **Плагин `brand-content-pipeline`** (`Content factory/`) — мультибрендовая
  структура, валидаторы кодом, калибровка голоса по экспорту, банк CTA.

# 03. Процессы

Завод это не одна линия, а четыре контура.

| Контур | Когда | Частота |
|---|---|---|
| **A. Онбординг** | новый тенант | один раз, см. `02-онбординг.md` |
| **B. Недельный цикл** | план → производство → публикация | еженедельно, основной |
| **C. Внеплановый вход** | «напиши пост про X» посреди недели | несколько раз в неделю |
| **D. Обратная связь** | метрики → выводы → правка стратегии | еженедельно + сводка раз в месяц |

# Контур B · Недельный цикл

```
пт 10:00   С0  триггер: расписание или «план на неделю»
     ↓
     🔍     С1  ресёрч + метрики прошлой недели        → топик Ресёрч
     ↓         (авто, ~10 мин, человек не участвует)
     🎯     С2  план недели                            → карточка в General
     ↓                                            ⏸ РЕШЕНИЕ 1: план
     ├──→ ✍️  С3  тексты батчем                        → топик На ревью
     │                                            ⏸ РЕШЕНИЕ 2: тексты
     └──→ 🎬  С4  сценарии Reels                       → топик Reels
     ↓                                            ⏸ РЕШЕНИЕ 3: сценарии
     🎨     С5  визуал под утверждённые тексты         → топик Дизайн
     ↓                                            ⏸ РЕШЕНИЕ 4: визуал
     📤     С6  комплект в очередь                     → топик Очередь
     ↓                                            ⏸ РЕШЕНИЕ 5: публикация
     📤     С7  публикация по расписанию
     ↓
     🔍     С8  метрики +24ч / +72ч / +7д              → топик Метрики
     ↓
            вход в С1 следующей недели
```

Работают С0–С7. Не работает С1 (ресёрч) и С8 (метрики): Ресёрчер зовёт модель только на распаковке профиля.

## Две ловушки цикла

**Пять точек решения — это ловушка.** При семи постах получается до 28 нажатий
в неделю. Через две недели человек перестанет нажимать, и завод встанет.

Решение — **батчевое утверждение**: одна карточка на весь батч с
разворачиванием по одному и кнопкой «взять все». Индивидуальная карточка
остаётся только там, где человек нажал «переделать».

**Человек это блокирующее звено.** Не утвердил план в пятницу — вся неделя
стоит.

| Когда | Что |
|---|---|
| сб 12:00 | `🎯 План недели ждёт решения, 7 тем → [открыть]` |
| вс 18:00 | `⚠️ Завтра понедельник, план не утверждён. Утром постить нечего.` |
| пн утро | `📤 Слот понедельника пуст. Публиковать нечего.` |

**Автоутверждения по таймауту нет.** Коробка, которая сама выпускает
непрочитанное, теряет доверие с первого промаха, а вернуть его дороже, чем
пропустить день.

## С1 · Ресёрч

Три уровня наблюдения:

| Уровень | Что это | Меняется |
|---|---|---|
| **Индустрия** | регулирование, деньги, крупные игроки, рынок труда | месяцы |
| **Ниша** | что происходит у тех, кто делает то же самое | недели |
| **Инструменты** | релизы, фичи | дни |

Инструменты меняются быстрее всего и соблазняют больше всего — там самый
жёсткий фильтр.

### Новость, тренд, сдвиг

| | Что это | Годен | Как писать |
|---|---|---|---|
| **Новость** | одно событие | 7–14 дней | «что произошло и что с этим делать» |
| **Тренд** | три события об одном | 1–3 месяца | «это уже не случайность, вот куда идёт» |
| **Сдвиг** | тренд, который держится квартал | полгода+ | «правила поменялись, вот новые» |

**Правило трёх.** Одна новость это новость. Три об одном за месяц — тренд,
и о нём можно писать как о направлении. Срок годности не декоративный: он не
даёт поставить в план тему, которая протухнет до даты выхода.

### Карточка новости, готовой к посту

**Новость без строки «что с этим делать» в дайджест не попадает.**

```markdown
### Claude научился работать с таблицами напрямую
**Уровень:** инструменты · **Годен до:** 27.08 · **Заряд:** useful discovery

**Что произошло.** Anthropic открыл доступ к работе с Excel и Google Sheets
без выгрузки. [источник](url), 12.08.2026

**Кому важно.** Аналитикам и маркетологам, которые сводят отчёты руками.
Сегмент А из ЯДРА.

**Что делать.** Взять один отчёт, который собираешь каждую неделю,
и отдать его целиком: файл на вход, готовая сводка на выход.

**Угол для поста.** «Отчёт, который я больше не собираю руками»
→ рубрика «Приём недели», Telegram, среда

**Чего не делать.** Не пересказывать список фич. Пост про свой отчёт,
а не про релиз.
```

Поля «угол» и «чего не делать» — то, ради чего это пишется: Стратегу не надо
переизобретать тему, Редактору не надо гадать.

### Недельная сводка

```
Коротко · Индустрия · Ниша · Инструменты · 🇷🇺 Российский рынок ·
🌍 Зарубежные: механики · Тренды · Понедельничная рубрика ·
Что взять в план · Чего не удалось собрать
```

| Раздел | Кому | Что делают |
|---|---|---|
| Что взять в план | 🎯 Стратег | дожимает заготовку до темы со своим углом |
| Понедельничная рубрика | ✍️ Редактор | пишет новостной пост |
| Механики | 🎬 Редактор Reels | берёт приём на тему из плана |
| Тренды | 🎯 Стратег | ставит большой темой, не новостью |
| Дырки конкурентов | 🎯 Стратег | самый ценный вход: тема, которую никто не закрыл |

### Бесплатные источники

| | Доступ | Что получаем |
|---|---|---|
| **Telegram** | ✅ `t.me/s/<канал>` — публичная веб-версия | тексты постов **и просмотры**, без авторизации и лимитов |
| **YouTube** | ✅ Data API, 10 000 единиц в сутки бесплатно | просмотры, лайки, комментарии, теги. Поиск 100 единиц, детали 1 |
| **Instagram** | 🔴 только чтение глазами | массовый скрейпинг нарушает ToS. 10–15 аккаунтов в неделю вручную |

`t.me/s/` закрывает весь конкурентный анализ в Telegram бесплатно — ровно те
данные, ради которых платят за TGStat. Механики коротких видео разбираются на
YouTube Shorts: они те же, что в Reels, а данные полные.

**Как найти конкурентов, если имён не назвали:**

1. Собрать 5–8 запросов из ЯДРА: ниша + боли + продукт
2. Прогнать по YouTube Data API, отсортировать по просмотрам
3. Те же запросы через поиск Telegram, открыть найденное как `t.me/s/`
4. Раскрутить снежный ком: «похожие каналы», кого упоминают
5. Отфильтровать и показать на подтверждение

| Фильтр | Порог |
|---|---|
| **Живой** | публиковал за последние 30 дней |
| **Сопоставимый** | база в 3–20 раз больше текущей |
| **Пересекается** | та же боль, та же аудитория |

**Правило сопоставимости важнее остальных.** Смотреть надо не на топ ниши, а
на тех, кто впереди на шаг: у канала с миллионом другая механика роста, и
копировать её с базы в 340 человек бессмысленно.

**Свои данные читаются раньше чужих.** Комментарии, вопросы в личку, что
спрашивают на созвонах — стоит ноль, сигнал сильнее любого конкурентного
анализа.

## С2 · План и решение 1

Стратег собирает план по слоям, потом кладёт батч в дашборд. Механика решения
в `05-дашборд.md`.

**План не выходит без свежего ресёрча.** Дайджеста за текущую неделю нет —
Стратег запускает Ресёрчера сам, разрешения не спрашивает.

**Круг переделки ограничен двумя.** На третий:

```
🎯 Переписал дважды, обе не подошли. Похоже, я не понимаю, что нужно.
   Скажи своими словами, о чём должен быть пост вторника, возьму как есть.
```

Бесконечная карусель переделок — тихий способ убить онбординг.

## С3 · Тексты

Батчем, карточками в топик `✍️ На ревью`. Дашборд здесь не выигрывает: пост
надо прочитать целиком.

## С6–С7 · Очередь и публикация

| Режим | Что делает |
|---|---|
| `auto` | публикует по расписанию, репортит фактом |
| `approve` | кладёт карточку с превью, ждёт решения |
| `manual` | собирает пакет и отдаёт человеку |

**Превью показывает пост ровно так, как он будет выглядеть на площадке**:
вёрстка, обрезка по лимиту, картинки в порядке публикации. Так ловится
большинство ошибок оформления.

Проверка перед отправкой (`check_bundle`):

1. Комплект собран: текст + визуал + теги под эту площадку
2. Текст и визуал относятся к одному id темы
3. Ничего из `guardrails.forbidden_topics`
4. Тема с `requires_approval` имеет запись об утверждении
5. Слот свободен, дубля на этот день нет
6. Токен площадки жив

Не сошлось — не публиковать, сказать, что именно.

**Пропуск слота это событие, о нём говорят.** Тема с прошедшей датой без
публикации переводится в `skip` с обязательной причиной.

## С8 · Метрики

Окна: `+24ч` · `+72ч` · `+7д`. Для YouTube ещё `+30д` — там трафик поисковый
и приходит позже.

**Снимки разного возраста не сравниваются.** Вчерашний пост против недельного
это не сравнение. Все выводы по одному окну, по умолчанию `+72ч`.

**При растущей базе смотреть ER, а не абсолют.** Пост на 34 подписчиках и на
500 в абсолютных числах несопоставимы.

### Скриншоты как полноценный вход

Работает с первого дня, остаётся навсегда для того, что API не отдаёт.

| Площадка | Что снимать |
|---|---|
| **Telegram** | 🥇 **просто лента канала** — просмотры видны под каждым постом |
| | Канал → Статистика (от 50 подписчиков) |
| **Instagram** | Профессиональный аккаунт → Статистика → Контент |
| **YouTube** | Studio → Аналитика → Контент |

Правила разбора:

- Читать построчно, ничего не додумывать. Обрезанная строка помечается.
- **Нет колонки — поле пустое, не ноль.** Ноль означает «реально ноль».
- Обрезанные заголовки не дописывать.
- Разные скрины — разные периоды, описать в `source`.

**Подтверждение перед записью обязательно:** OCR ошибается молча, и кривая
цифра отравит всю аналитику.

```
🔍 Прочитал 7 постов. Проверь три спорных:
   пост от 11.08   просмотры 1 240 или 1 249? [размыто]
   пост от 13.08   заголовок обрезан, сопоставил по дате
   пост от 14.08   охвата на скрине нет, оставил пустым
[✅ Верно]  [✏️ Поправлю]
```

**Возраст снимка.** Скриншот не несёт информации о том, сколько посту дней.
Ресёрчер считает возраст от даты публикации сам и предупреждает при смешивании:

```
Посты в выгрузке разного возраста, от 1 до 9 дней. Сравнивать нельзя.
Для недельных выводов беру окно +72ч, это 4 поста из 7.
```

# Контур C · Внеплановый вход

«Напиши пост про X» посреди недели.

1. Профильная роль делает работу
2. **Тема дописывается в план задним числом** с меткой `adhoc` — иначе
   статистика не сойдётся
3. Одна строка в ответе: «Тема добавлена в контент-план как внеплановая»

Согласование не нужно: просьба человека и есть согласование. Ресёрч на
внеплановую тему тоже не нужен.

# Контур D · Обратная связь

Ресёрчер владеет обратной связью завода. После каждой публикации:

```
дата · id темы · формат
Угол: <какой> · Заряд: <какой> · Тип заголовка: <какой>
Самооценка редактора при выдаче: N из 25
За что зацепится: <строка>  ·  Где рассыпется: <строка>
Результат: охват, сохранения, дата снятия цифр
Вывод: что подтвердилось, что нет
```

Раз в четыре недели, когда набирается 8–10 записей — сводка **«Что
подтвердилось»**: какие углы, заряды и типы заголовков работают, какие
проседают. Сводка становится слоем контекста для Стратега и Редактора.

**Своя статистика перебивает чужие механики.** Приём из разбора конкурентов
это гипотеза, цифры бренда это факт.

# Расписание

Две сводки, два расписания. Порядок неслучаен: ресёрч кормит план, метрики
закрывают предыдущий цикл. Поставить их в один день — потерять смысл обоих.

| Сводка | Дефолт | Логика |
|---|---|---|
| 🔍 Ресёрч ниши | пт 10:00 | **до** сборки плана |
| 📊 Метрики | пн 11:00 | **после** закрытия недели, когда цифры дозрели |

Спрашивается на онбординге. Запрос статистики называет цену пропуска:

```
🔍 Неделя закрылась. Кинь скрин статистики, посчитаю выводы.

За прошлую неделю данных нет, дайджест собрать не смогу — стратегия
на следующую неделю пойдёт вслепую.

[📸 Сейчас пришлю]  [⏭ Пропустить неделю]
```

Вторая строка важнее первой: без неё пропуск выглядит бесплатным.
